# 大綱：社區共享書櫃續辦一年，一頁式計畫

交給 Claude Design。在 Claude Code 裡用 `/design` 加這份大綱，或貼進 claude.ai 對話並說「照這份大綱做一張一頁式計畫」。內容跟成果報告那份 Marp 範例是同一個虛構專案，這份是貼在大廳公告欄的版本。

- 目的：讓住戶在電梯口看一分鐘，就知道書櫃續辦後有什麼改變、要怎麼幫忙
- 讀者：社區住戶，多數沒看過期末報告
- 尺寸：A3 直式，要能列印，也要能存成圖片傳到社區群組
- 語氣：像公告，口語、短句
- 外觀：用預設的設計系統；沒有的話用簡單的雙色，留白多
- 文字：數字照大綱原文，不要改寫

## 版面由上到下

### 1. 標題區

- 大標：共享書櫃，再開一年
- 副標：從下個月起，借書會收到到期提醒
- 版面：滿版寬的標題帶，大標佔最多面積

### 2. 半年成績

- 一排三個大數字，每個數字下面一行說明
  - 1,240 本：半年借出
  - 312 戶：已登記
  - 78%：準時歸還
- 備註：78% 旁邊加一行小字「目標 90%，下半年要補的就是這個」

### 3. 續辦後有什麼改變

- 版面：左右兩欄對照，左欄「以前」右欄「從下個月起」
  - 以前：到期日寫在書裡的紙條；從下個月起：每週一在社區群組公告本週到期書單
  - 以前：逾期沒有規則；從下個月起：逾期兩週暫停借閱一個月
  - 以前：童書常常被借光；從下個月起：每月加購童書

### 4. 怎麼借

- 版面：由左到右三步，每步一個圖示加一句話
  - 掃書櫃旁的 QR code
  - 登記門牌號碼
  - 兩週內歸還到原書櫃

### 5. 想幫忙

- 版面：一張強調的卡片，跟上面的區塊有明顯區隔
  - 標題：志工從 6 人增加到 8 人
  - 內容：每月兩班，每班一小時，整理新捐的書
  - 報名：找管理室登記

### 6. 頁尾

- 一行小字：書櫃試辦小組｜管委會第 2 季會議通過

## 交付後要核對

- 三個數字與大綱一致
- 列印成 A3 時，最小的字在一公尺外看得清楚
- 頁面上沒有出現大綱沒有的人名、電話或網址
