# 寫標題、刪字、算張數

兩條輸出路線都適用。Marp 路線另外要守 `marp-rules.md` 的字數上限與 class 規則。

## 結論式標題

內容頁的標題寫一句結論，說出這頁要觀眾記住什麼。封面、目錄、章節頁、結尾頁可以用主題詞。

| 主題詞 | 結論句 |
|---|---|
| 研究背景 | 夜間公車班次少，晚班學生通勤時間多出一倍 |
| 問卷結果 | 七成受訪者願意為準時多付 5 元 |
| 競品分析 | 三家對手都沒有做到店取餐，這是空檔 |
| 研究限制 | 只調查一所學校，結果不能推到其他城市 |

檢查方式是只讀所有標題，從頭讀到尾。讀得出整個故事就過，讀不出來就重寫標題，不是加頁。

### 要避開的標題寫法

| 寫法 | 問題 | 改法 |
|---|---|---|
| 「A 與 B 各說一段，合起來才完整」 | 描述投影片結構，沒說結論 | 直接說合起來得到什麼 |
| 「三個讓使用者留下來的關鍵」 | 冗長的名詞組，觀眾還是不知道是哪三個 | 改成動詞開頭的結論句，或把三個直接寫出來 |
| 「三個問題，本案各提一個解法」 | 列舉結構的描述 | 說出三個解法的共同方向 |
| 「降低成本，同時提升滿意度」 | 兩個並列主張搶重點 | 選比較核心的放標題，另一個放結論列 |

## 降噪

畫面乾淨靠的是少頁、少字，不是加裝飾。

- 每頁條列最多 5 點，子項目最多一行。超過就拆頁。
- 粗體只給真正的警告或關鍵數字，一頁最多一兩處。
- 表格不超過 6 欄，欄位太多就拆成兩張表或改用數字方塊。
- 背景的幾何裝飾只放封面和章節頁，內容頁不放。
- 頁面上不放導覽、撰寫說明、「本頁介紹」這類文字，要講的話放講者備註。圖片來源可以留一行小字。

## 張數粗估

一頁講一件事，多一頁沒關係，不要為了湊張數刪內容。下表只當起點，時長以使用者給的為準。

| 場合 | 主簡報 | 附錄 |
|---|---|---|
| 課堂報告（10 至 15 分鐘） | 10 至 15 頁 | 0 至 3 頁 |
| 計畫書口試（15 分鐘） | 15 至 18 頁 | 5 至 8 頁 |
| 學位論文口試（40 至 60 分鐘） | 40 至 55 頁 | 8 至 12 頁 |
| 商業提案（20 分鐘） | 15 至 20 頁 | 0 至 5 頁 |

口試的附錄放方法細節與常被問的表格（樣本描述、量表信效度、分析方法的選擇理由、研究限制），用附錄分隔頁（`appendix-divider`）跟正文隔開，被問到再翻。

## 常見母板對到哪個版型

自己手寫過 Marp 簡報的人，常用的頁面大多對得到目錄裡的版型。

| 常見的頁 | 版型 |
|---|---|
| 封面 | 封面（`cover`） |
| 章節過場 | 章節頁（`section`） |
| 標題加條列，底下一句小結 | 結論列（`conclusion-bar`） |
| 左右兩欄 | 雙欄對照（`two-column`），class 是 `column`，舊寫法 `col` 要改掉 |
| 一張圖加出處 | 截圖（`screenshot`） |
| 資料表 | 表格（`table`） |
| 附錄分隔加附錄內容 | 附錄分隔頁（`appendix-divider`） |
