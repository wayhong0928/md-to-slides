怎麼開始

  • 只改範本：上面選好場合和主題，按「下載起手包」，解壓縮後用 VS Code 打開整個資料夾，裝 Marp for VS Code 就能預覽。VS Code 問要不要信任資料夾時選信任，不然主題不會載入。
  • 要輸出 PDF 或 PPTX：需要 Node.js 18 以上，照 README 的 Quick Start 裝好，一行指令輸出三種格式。

限制

範例版的內容是虛構的，數字和案例都要換成你自己的。起手包裡沒有版面檢查，填完先在 VS Code 搜尋「【填：」確認都填了；要完整檢查，把 slides.md 拿回本工具跑 npm run check。

同一套的工具

網站論文指南研究方法、論文寫作和口試，每一站該怎麼做的說明。 Claude Code 外掛thesis-toolkit幫你收斂題目、稽核研究問題、檢查學術寫法的 SKILL。 Obsidian 範本論文筆記庫範本文獻筆記、構念卡和假說推導放在同一個筆記庫，寫第二、三章時直接取材。
