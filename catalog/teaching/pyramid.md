## 骨架

```markdown
# 【標題：三層的共同邏輯】

<div class="pyramid">
<div class="top"><b>【頂層】</b>【說明】</div>
<div class="mid"><b>【中層】</b>【說明】</div>
<div class="bot"><b>【底層】</b>【說明】</div>
</div>
```

## 範例

```markdown
# 節水措施依難度分三層

<div class="pyramid">
<div class="top"><b>設備改造</b>投資大，效果最明顯</div>
<div class="mid"><b>制度調整</b>用水量計費與公告</div>
<div class="bot"><b>日常習慣</b>隨手關水，人人都能做</div>
</div>
```
