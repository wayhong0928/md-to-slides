## 骨架

```markdown
# 【標題：結論式】

<div class="tip">【小技巧：做了會更好的事】</div>
<div class="warning">【注意：容易忽略的條件】</div>
<div class="danger">【禁止：做了會出問題的事】</div>
```

## 範例

```markdown
# 清洗水槽前先確認三件事

<div class="tip">清洗選在連續晴天的前一天，水槽乾得快。</div>
<div class="warning">進入水槽前要先通風，並有第二人在場。</div>
<div class="danger">不要用含氯清潔劑，會傷害水槽內襯。</div>
```
