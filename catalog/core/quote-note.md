## 骨架

```markdown
# 【填：標題，這段引言要說明什麼】

<div class="quote">【填：引言原文，一到兩句】<small>【填：出處，作者、年份或來源】</small></div>

- 【填：附註一，這句話為什麼重要】
- 【填：附註二，和本研究的關係】
```

## 範例

```markdown
# 受訪者最在意的是維護

<div class="quote">水槽裝好以後沒人管，一個夏天就長蚊子了。<small>受訪者 A（虛構），總務處職員</small></div>

- 維護責任歸屬不清，是第一個被提到的問題
- 方案要附上每月清洗的分工表
```
