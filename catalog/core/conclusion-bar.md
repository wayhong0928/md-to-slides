## 骨架

```markdown
# 【填：標題】

- 【填：論點一】
- 【填：論點二】
- 【填：論點三】

<div class="conclusion">【填：結論，一句話講這頁要觀眾記住什麼，20 字內】</div>
```

## 範例

```markdown
# 試辦成本可以控制

- 設備費約三十萬，由環境社與總務處分攤
- 維護由志工輪值，每月兩小時
- 第一年只裝一棟，效果不好隨時停止

<div class="conclusion">先小規模試辦，用一個學期的數據再決定要不要擴大。</div>
```
