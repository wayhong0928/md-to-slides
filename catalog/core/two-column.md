## 骨架

```markdown
# 【標題：結論式，說出這頁要比較什麼】

<div class="columns">
<div class="column">

### 【左欄標題】

- 【重點一】
- 【重點二】

</div>
<div class="column">

### 【右欄標題】

- 【重點一】
- 【重點二】

</div>
</div>
```

## 範例

```markdown
# 兩種蓄水設計各有取捨

<div class="columns">
<div class="column">

### 地下水槽

- 不佔地面空間
- 施工費用較高

</div>
<div class="column">

### 屋頂水塔

- 施工簡單
- 需要加固樓板

</div>
</div>
```
