# Prompt 小抄

在 VS Code 的 Copilot Chat（agent 模式）或其他 AI 工具裡，複製下面的 prompt，把【】裡的內容換成自己的再送出。常駐規則寫在 `AGENTS.md` 和 `.github/copilot-instructions.md`，這裡的 prompt 不用再重複規則。

## 起手

```text
讀 slides.md 和 example.md。先問我三件事：簡報主題、聽眾是誰、報告時間多長。
等我回答後，把 slides.md 裡的【填：…】換成我的內容；我沒提供的資料先留著，最後列出還缺哪些。
```

## 換主題

```text
把 slides.md 的主題換成【主題 id，例如 midnight】，只改 frontmatter 的 theme: 那一行，其他內容都不要動。
```

## 加一頁某種版型

```text
在 slides.md 第【頁碼】頁後面加一頁【版型中文名，例如時間軸】，內容是【這頁要講什麼】。
照 slides.md 或 example.md 裡同一種版型的頁面寫法；如果這份範本裡沒有這種版型，先跟我說，不要自己發明 class。
```

## 精簡文字

```text
檢查 slides.md 每一頁：標題超過 25 字、條列超過 5 點、每點超過 30 字的，改短或拆成兩頁。
意思不能變，數字和人名不能改。改完列出你動了哪幾頁。
```

## 新手視角審查

```text
假設你是第一次聽到這個主題的【聽眾，例如大一新生】，讀完 slides.md 後告訴我：
哪幾頁看不懂、哪些詞需要先解釋、哪兩頁之間跳太快。只列問題和頁碼，先不要改檔案。
```

## 專業視角審查

```text
假設你是這個領域的【專業角色，例如指導教授、技術主管】，讀完 slides.md 後告訴我：
哪些結論證據不夠、哪些數字缺出處、哪裡講得太絕對。只列問題和頁碼，先不要改檔案。
```
